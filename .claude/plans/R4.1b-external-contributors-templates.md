# R4.1b — External Contributors & Templates
# ═══════════════════════════════════════════════════════════════════════════════

## Goal

Enable **external contributor** data collection via pluggable templates. An external
contributor is someone not in the system (from another institution, industry partner,
international collaborator). Different KPIs may need different external fields
(ORCID for researchers, company name for industry partners).

Depends on: R4.1a (ContributorRole, BenefitType)

---

## Locked Decisions

| # | Decision |
|---|----------|
| D1 | External contributor templates use the **same field schema** as achievement form fields (`AchievementFieldConfig`) |
| D2 | Three pre-seeded templates: Default, Research Collaborator, Industry Partner |
| D3 | Each KPI links to one external template (or falls back to default) |
| D4 | External scope: NATIONAL or INTERNATIONAL — affects required fields |
| D5 | External contributors are **excluded from reward calculation** by default |
| D6 | External's excluded share: configurable — RETURN_TO_POOL, SPLIT_INTERNAL, NO_REDISTRIBUTION |

## Schema (2 new models, 2 enums)

### Enums
```prisma
enum ContributorType {
  INTERNAL
  EXTERNAL
}

enum ExternalContributorScope {
  NATIONAL
  INTERNATIONAL
}
```

### ExternalContributorTemplate
```prisma
model ExternalContributorTemplate {
  id          String   @id @default(cuid())
  tenantId    String
  name        String   // "Research Collaborator"
  description String?
  fields      Json     // AchievementFieldConfig[] — reuses same schema
  isDefault   Boolean  @default(false)
  isActive    Boolean  @default(true)
  sortOrder   Int      @default(0)
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
  tenant      Tenant   @relation(fields: [tenantId], references: [id], onDelete: Cascade)
  kpiConfigs  KpiContributorConfig[]

  @@index([tenantId, isActive])
}
```

### KpiContributorConfig
```prisma
model KpiContributorConfig {
  id                        String   @id @default(cuid())
  kpiDefinitionId           String   @unique
  externalContribTemplateId String?
  allowExternalContributors Boolean  @default(true)
  duplicateCheckFields      Json?    // ["doi", "applicationNumber"]
  creditSumMode             String   @default("MUST_EQUAL_100")
                                     // "MUST_EQUAL_100" | "MAX_100" | "UNCAPPED"
  createdAt                 DateTime @default(now())
  updatedAt                 DateTime @updatedAt
  kpiDefinition             KpiDefinition @relation(fields: [kpiDefinitionId], references: [id], onDelete: Cascade)
  externalContribTemplate   ExternalContributorTemplate? @relation(fields: [externalContribTemplateId], references: [id])
}
```

### Relations on Existing Models
- **Tenant**: add `externalContribTemplates ExternalContributorTemplate[]`
- **KpiDefinition**: add `contributorConfig KpiContributorConfig?`

## Validation Rules
- Template `fields` must contain at least `name` (TEXT, required) and `affiliation` (TEXT, required)
- Only one template can be `isDefault` per tenant
- KpiContributorConfig.creditSumMode must be one of: MUST_EQUAL_100, MAX_100, UNCAPPED
- duplicateCheckFields values must match field keys in the KPI's achievementFormConfig
- Cannot archive template if referenced by any KpiContributorConfig
