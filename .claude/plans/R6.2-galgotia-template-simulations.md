# R6.2 - Galgotia Template Simulations

This file records the payout behavior actually implemented for the seeded Galgotia templates.

## Journal Publication

### Case Matrix
- Case 1: first author `35%`, corresponding author `35%`, GU co-authors share `30%`
- Case 2: first author `50%`, corresponding author `50%`
- Case 3: first or corresponding author `60%`, GU co-authors share `40%`
- Case 4: first or corresponding author `100%`
- Case 5: GU co-authors share only the `40%` GU pool

### Implemented model
- Quartile amount is selected by `journalQuartile`.
- Authorship case is selected by `authorshipCase`.
- Distribution is `CREDIT_PERCENT_SPLIT`.
- Verifier or submitter enters the exact allowed credit percentages.
- Case 5 uses reduced tier amounts instead of post-generation manual adjustment:
  - `Q1_CASE_5 = 12000`
  - `Q2_CASE_5 = 10000`
  - `Q3_CASE_5 = 6000`
  - `Q4_CASE_5 = 4000`

### Sample outcomes
- `Q1 + CASE_1`, credits `35/35/15/15`
  - total payout = `30000`
  - amounts = `10500 / 10500 / 4500 / 4500`
- `Q2 + CASE_2`, credits `50/50`
  - total payout = `25000`
  - amounts = `12500 / 12500`
- `Q3 + CASE_3`, credits `60/20/20`
  - total payout = `15000`
  - amounts = `9000 / 3000 / 3000`
- `Q4 + CASE_4`, credits `100`
  - total payout = `10000`
  - amount = `10000`
- `Q1 + CASE_5`, credits `50/50`
  - total payout = `12000`
  - amounts = `6000 / 6000`

### Guardrails
- DOI duplicate policy blocks repeat reward claims for the same paper.
- External contributors can be recorded, but payout-eligible calculations exclude them for this template.

## Textbook Authored
- Fixed amount `25000`
- `EQUAL_SPLIT`
- Example:
  - 2 eligible GU authors -> `12500` each
  - 1 external + 2 eligible GU authors -> external excluded, `12500` each to GU authors

## Edited Book
- Fixed amount `15000`
- `EQUAL_SPLIT`
- Same-ISBN cross-template policy warning appears when the same contributor also has a book chapter claim for that ISBN.

## Book Chapter
- Fixed amount `5000`
- `EQUAL_SPLIT`
- Same-ISBN cross-template policy warning appears when the same contributor also has an edited-book claim for that ISBN.

## PhD Awarded
- Fixed amount `18000`
- `ROLE_PERCENT_SPLIT`
  - `SUPERVISOR = 60%`
  - `CO_SUPERVISOR = 40%` equal split within group
- Example:
  - supervisor + 2 co-supervisors -> `10800 / 3600 / 3600`
  - sole supervisor -> `18000`

## Research Grant
- Amount = `10%` of `sanctionedAmount`
- `ROLE_PERCENT_SPLIT`
  - `PI = 60%`
  - `CO_PI = 40%` equal split within group
- Example:
  - sanctioned amount `1000000`
  - reward pool `100000`
  - PI + 2 Co-PIs -> `60000 / 20000 / 20000`

## Consultancy Project
- Amount = `70%` of `savings`
- `EQUAL_SPLIT`
- Example:
  - savings `100000`
  - reward pool `70000`
  - 3 eligible GU consultants -> `23333.34 / 23333.33 / 23333.33` after rounding

## Patent Filing
- Fixed amount `2000`
- `EQUAL_SPLIT`
- Reward triggers only when `applicantIsGU = true`
- Example:
  - 2 inventors -> `1000 / 1000`
  - `applicantIsGU = false` -> no reward rows

## International Conference Convenor
- Fixed amount `5000`
- `DIRECT_OWNER`
- Reward triggers only when `proceedingsScopusIndexed = true`

## FDP/STC/VAC/Training/Workshop Convenor
- Fixed amount `5000`
- `DIRECT_OWNER`
- Reward triggers only when:
  - `isSponsored = true`
  - `totalHours >= 30`

## Conference Paper
- Fixed amount `5000`
- `EQUAL_SPLIT`
- Reward triggers only when `receivedUniversityFunding = false`
- Example:
  - 2 eligible GU authors -> `2500 / 2500`
- Reviewer still manually checks the policy limit of max 2 claims per semester.

## EDP/MDP Convenor
- Amount = `70%` of `savings`
- `CREDIT_PERCENT_SPLIT`
- Example:
  - savings `100000`
  - reward pool `70000`
  - credits `70/30`
  - amounts `49000 / 21000`

## Same-ISBN Reviewer Warning
- Scenario:
  - contributor submits `GU_SCOPUS_EDITED_BOOK` for ISBN `978-X`
  - same contributor later submits `GU_SCOPUS_BOOK_CHAPTER` for ISBN `978-X`
- Result:
  - submission remains allowed
  - `duplicateCheckResult.matches` includes a `POLICY_WARNING`
  - reviewer sees the warning and manually enforces the Rs. 20,000 same-book combined policy
