# R4.2a — Reward Policies & Categories
# ═══════════════════════════════════════════════════════════════════════════════

## Goal

Create **standalone, reusable Reward Policies** as a tenant-wide pluggable entity.
Each policy defines categories/tiers (Q1/Q2/Q3, grant ranges), benefit pools per tier
(capped amounts), role-wise splits, and calculation methods. Policies are **versioned
with effective dates and expiry** — new versions replace old ones. KPIs plug into
policies like they plug into field templates.

Depends on: R4.1a (BenefitType, ContributorRole)

---

## Locked Decisions

| # | Decision |
|---|----------|
| D1 | Reward policies are **tenant-wide standalone entities**, not embedded in KPIs |
| D2 | One KPI links to one active policy. Same policy can be shared across multiple KPIs. |
| D3 | Policies are **versioned**: v1 (expired) → v2 (active) → v3 (scheduled) |
| D4 | Active policy is **locked** — cannot edit. To change, create new version. |
| D5 | Policy version is **locked to achievement at verification time** — future policy changes don't affect old rewards |
| D6 | Categories within a policy define qualification rules: auto (based on CATEGORY_FIELD) or manual (reporter picks) |
| D7 | 6 calculation methods: FIXED, PERCENTAGE, SLAB_PERCENTAGE, PER_UNIT, SCORE_MULTIPLIED, TIERED_MULTIPLIER |
| D8 | Multi-person strategy per role per category: SPLIT_WITHIN, REPEAT_PER_PERSON, FIXED_PER_PERSON |
| D9 | External contributor policy per category: EXCLUDE (default), INCLUDE |
| D10 | Pre-seed sample policies for common academic KPIs |
| D11 | **Policy resolution date** configurable per KPI link: VERIFIED_AT (default), SUBMITTED_AT, or ACHIEVEMENT_DATE |
| D12 | **Category progression** configurable per policy: ADDITIVE (stack rewards), REPLACEMENT (higher cancels lower), DIFFERENTIAL (pay difference only) — handles patent filed→granted, grant applied→sanctioned |

## Schema (5 new models, 2 enums)

### Enums

```prisma
enum RewardPolicyStatus {
  DRAFT
  ACTIVE
  SCHEDULED
  EXPIRED
  ARCHIVED
}

enum BenefitCalcMethod {
  FIXED                // reward = fixedAmount
  PERCENTAGE           // reward = actualValue × percentage (needs VALUE_FIELD)
  SLAB_PERCENTAGE      // reward = sum(slab ranges × slab rates) (needs VALUE_FIELD)
  PER_UNIT             // reward = unitCount × ratePerUnit (needs UNIT_FIELD)
  SCORE_MULTIPLIED     // reward = baseAmount × (score / 100)
  TIERED_MULTIPLIER    // reward = baseAmount × tierMultiplier (based on score ranges)
}
```

### Models

#### RewardPolicy
```prisma
model RewardPolicy {
  id                String             @id @default(cuid())
  tenantId          String
  code              String             // "PUB_REWARDS_2025", "GRANT_INCENTIVE_2025"
  name              String             // "Research Publication Rewards"
  description       String?
  version           Int                @default(1)
  status            RewardPolicyStatus @default(DRAFT)
  effectiveFrom     DateTime?          // null = not yet scheduled
  effectiveTo       DateTime?          // null = no expiry (until replaced)
  previousVersionId String?            // link to v1 for history
  approvedByUserId  String?
  approvedAt        DateTime?
  categoryProgression String            @default("ADDITIVE")
                                       // "ADDITIVE" — each tier's rewards stack (patent: filed ₹25K + granted ₹1L)
                                       // "REPLACEMENT" — higher tier cancels lower (only latest tier's reward kept)
                                       // "DIFFERENTIAL" — pay difference only (granted ₹1L - filed ₹25K = ₹75K)
  isActive          Boolean            @default(true)
  createdAt         DateTime           @default(now())
  updatedAt         DateTime           @updatedAt
  tenant            Tenant             @relation(fields: [tenantId], references: [id], onDelete: Cascade)
  previousVersion   RewardPolicy?      @relation("PolicyVersionChain", fields: [previousVersionId], references: [id])
  nextVersions      RewardPolicy[]     @relation("PolicyVersionChain")
  categories        RewardPolicyCategory[]
  linkedKpis        KpiRewardPolicyLink[]

  @@unique([tenantId, code, version])
  @@index([tenantId, status])
  @@index([tenantId, isActive])
}
```

model RewardPolicyCategory {

  rewardPolicy        RewardPolicy @relation(fields: [rewardPolicyId], references: [id], onDelete: Cascade)

  @@index([rewardPolicyId, sortOrder])

#### CategoryBenefitPool
```prisma
model CategoryBenefitPool {
  id                        String                 @id @default(cuid())
  categoryId                String
  benefitTypeId             String
  calcMethod                BenefitCalcMethod      @default(FIXED)
  // Method-specific config:
  fixedAmount               Float?                 // for FIXED, SCORE_MULTIPLIED, TIERED_MULTIPLIER (base)
  percentage                Float?                 // for PERCENTAGE
  cap                       Float?                 // max amount (for PERCENTAGE, SLAB, PER_UNIT)
  ratePerUnit               Float?                 // for PER_UNIT
  maxUnits                  Float?                 // for PER_UNIT cap
  slabs                     Json?                  // for SLAB_PERCENTAGE: [{min, max, rate}]
  tierMultipliers           Json?                  // for TIERED_MULTIPLIER: [{scoreMin, scoreMax, multiplier}]
  minScoreThreshold         Float?                 // minimum achievement score to qualify
  externalContributorPolicy String                 @default("EXCLUDE") // "EXCLUDE" | "INCLUDE"
  isActive                  Boolean                @default(true)
  createdAt                 DateTime               @default(now())
  updatedAt                 DateTime               @updatedAt
  category                  RewardPolicyCategory   @relation(fields: [categoryId], references: [id], onDelete: Cascade)
  benefitType               BenefitType            @relation(fields: [benefitTypeId], references: [id], onDelete: Restrict)

  @@unique([categoryId, benefitTypeId])
  @@index([categoryId])
}
```

#### CategoryRoleSplit
```prisma
model CategoryRoleSplit {
  id                    String               @id @default(cuid())
  categoryId            String
  contributorRoleId     String

  multiPersonStrategy   String               @default("SPLIT_WITHIN")

  createdAt             DateTime             @default(now())
  updatedAt             DateTime             @updatedAt
  category              RewardPolicyCategory @relation(fields: [categoryId], references: [id], onDelete: Cascade)
  contributorRole       ContributorRole      @relation(fields: [contributorRoleId], references: [id], onDelete: Restrict)

  @@unique([categoryId, contributorRoleId])
  @@index([categoryId])
}
```

## Validation Rules

### Policy
- `code` + `version` unique per tenant
- Only DRAFT can be edited (name, description, categories, pools, splits)
- ACTIVE cannot be edited — must create new version
- effectiveFrom < effectiveTo (if effectiveTo set)
- Cannot activate policy with no categories
- Cannot activate category with no benefit pools

### Categories
- `code` unique within policy
- qualificationRules JSON validated: each rule has `fieldKey`, `operator` (eq, neq, gt, gte, lt, lte, contains, in), `value`
- At least one category required before activation

### Benefit Pools
- One pool per benefitType per category (@@unique)
- calcMethod-specific validation:
  - FIXED: fixedAmount required
  - PERCENTAGE: percentage required, VALUE_FIELD must exist in KPI template
  - SLAB_PERCENTAGE: slabs[] required, ranges must not overlap, VALUE_FIELD required
  - PER_UNIT: ratePerUnit required, UNIT_FIELD must exist in KPI template
  - SCORE_MULTIPLIED: fixedAmount (as base) required
  - TIERED_MULTIPLIER: fixedAmount (as base) + tierMultipliers[] required, ranges no overlap

### Role Splits
- splitPercent sum ≤ 100% per category
- SPLIT_WITHIN: % is shared among all people in that role
- REPEAT_PER_PERSON: % is per person (total may exceed pool — capped at pool max)
- FIXED_PER_PERSON: fixedPerPersonAmount required, splitPercent ignored
