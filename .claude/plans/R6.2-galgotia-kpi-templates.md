# R6.2 - Galgotia KPI Templates MVP

## Scope
- Seeded system templates only.
- No new template infrastructure, no superadmin CRUD, no template versioning, no reward-engine primitives.
- Templates live in `SYSTEM_KPI_TEMPLATES` and are imported through the existing `applyTemplateToKpi()` flow.
- Category: `GALGOTIA_RD`

## Runtime Boundaries
- Use existing reward modes only: `EQUAL_SPLIT`, `ROLE_PERCENT_SPLIT`, `CREDIT_PERCENT_SPLIT`, `DIRECT_OWNER`, `PERCENT_OF_FIELD`.
- Human verifier remains responsible for documentary truth and policy checks that are not encoded as payout math.
- Do not rely on manual reward amount editing after reward generation.

## Manual Credit Rules
- Manual `creditPercent` entry is enabled only for:
  - `GU_SCOPUS_JOURNAL_PUBLICATION`
  - `GU_EDP_MDP_CONVENOR`
- Journal uses verifier-entered credits because the Galgotia authorship matrix cannot be represented safely with the legacy lead-author template logic.
- EDP/MDP uses verifier-entered credits because the policy requires a submitted distribution chart.

## External Contributor Handling
- For payout templates that only reward eligible GU contributors, external contributors may still be recorded but are auto-marked `isExcludedFromReward = true`.
- This applies to:
  - journal publication
  - textbook authored
  - edited book
  - book chapter
  - conference paper
- External contributor validation still uses the existing external template rules.

## Seeded Templates

### 1. `GU_SCOPUS_JOURNAL_PUBLICATION`
- Quartile amounts:
  - `Q1 = 30000`
  - `Q2 = 25000`
  - `Q3 = 15000`
  - `Q4 = 10000`
- Required extra form fields:
  - `journalQuartile`
  - `authorshipCase`
  - `impactFactor`
  - `totalAuthors`
  - `guAuthorsCount`
  - `selfDeclaration`
- Distribution: `CREDIT_PERCENT_SPLIT`
- Recurrence: `ONCE_PER_UNIQUE_KEY` using DOI duplicate policy
- Important implementation detail:
  - Cases 1 to 4 use full quartile amounts.
  - Case 5 is encoded as reduced base amount tiers:
    - `Q1_CASE_5 = 12000`
    - `Q2_CASE_5 = 10000`
    - `Q3_CASE_5 = 6000`
    - `Q4_CASE_5 = 4000`

### 2. `GU_SCOPUS_TEXTBOOK_AUTHORED`
- Fixed amount: `25000`
- Distribution: `EQUAL_SPLIT`
- Duplicate key: `isbn`
- External contributors are excluded from payout.

### 3. `GU_SCOPUS_EDITED_BOOK`
- Fixed amount: `15000`
- Distribution: `EQUAL_SPLIT`
- Duplicate key: `isbn`
- External contributors are excluded from payout.
- Manual review warning:
  - reviewer must check same contributor + same ISBN against book chapter claims for the combined Rs. 20,000 same-book policy.

### 4. `GU_SCOPUS_BOOK_CHAPTER`
- Fixed amount: `5000`
- Distribution: `EQUAL_SPLIT`
- Duplicate key: `isbn + chapterTitle`
- External contributors are excluded from payout.
- Manual review warning:
  - reviewer must check same contributor + same ISBN against edited-book claims for the combined Rs. 20,000 same-book policy.

### 5. `GU_PHD_AWARDED`
- Fixed amount: `18000`
- Distribution: `ROLE_PERCENT_SPLIT`
  - `SUPERVISOR = 60%`
  - `CO_SUPERVISOR = 40%` with equal split within the co-supervisor group
- Recurrence: `ONCE_PER_UNIQUE_KEY`
- Duplicate key: `enrollmentNumber`

### 6. `GU_RESEARCH_GRANT`
- Amount: `10%` of `sanctionedAmount`
- Distribution: `ROLE_PERCENT_SPLIT`
  - `PI = 60%`
  - `CO_PI = 40%` with equal split within the co-PI group
- Recurrence: `ONCE_PER_UNIQUE_KEY`
- Duplicate key: `sanctionNumber`

### 7. `GU_CONSULTANCY_PROJECT`
- Amount: `70%` of `savings`
- Distribution: `EQUAL_SPLIT`
- Duplicate key: `referenceNumber`

### 8. `GU_PATENT_FILING`
- Fixed amount: `2000`
- Distribution: `EQUAL_SPLIT`
- Reward tier gate:
  - `applicantIsGU = true`
- Duplicate key: `applicationNumber`

### 9. `GU_INTL_CONFERENCE_CONVENOR`
- Fixed amount: `5000`
- Distribution: `DIRECT_OWNER`
- Reward tier gate:
  - `proceedingsScopusIndexed = true`
- Duplicate key: `referenceNumber`

### 10. `GU_FDP_STC_VAC_TRAINING_CONVENOR`
- Fixed amount: `5000`
- Distribution: `DIRECT_OWNER`
- Reward tier gate:
  - `isSponsored = true`
  - `totalHours >= 30`
- Program options include:
  - `FDP`
  - `STC`
  - `VAC`
  - `Training Program`
  - `Hands-on Workshop`
- Duplicate key: `referenceNumber`

### 11. `GU_CONFERENCE_PAPER`
- Fixed amount: `5000`
- Distribution: `EQUAL_SPLIT`
- Reward tier gate:
  - `receivedUniversityFunding = false`
- Recurrence: `RECURRING`
- Duplicate key: `conferenceName + paperTitle`
- Reviewer-only rule:
  - maximum 2 claims per faculty per semester is not auto-enforced in this release

### 12. `GU_EDP_MDP_CONVENOR`
- Amount: `70%` of `savings`
- Distribution: `CREDIT_PERCENT_SPLIT`
- Duplicate key: `referenceNumber`
- Program options:
  - `EDP`
  - `MDP`

## Production Seed
- Command: `npm run seed:galgotia`
- Script:
  - validates the 12 Galgotia template payloads
  - runs `seedSystemKpiTemplates()`
  - verifies all expected Galgotia template codes exist
  - revalidates stored payloads
  - exits non-zero on failure
