# R4.1a — Benefit Types & Contributor Roles
# ═══════════════════════════════════════════════════════════════════════════════

## Goal

Create tenant-wide **Benefit Types** (what rewards exist) and **Contributor Roles**
(what roles people play in achievements). These are reusable building blocks that
KPIs and reward policies plug into. Extend field templates with **markers** for
the calculation engine.

Standalone — no dependencies. Foundation for R4.1b, R4.1c, R4.2a, R4.2b.

---

## Locked Decisions

| # | Decision |
|---|----------|
| D1 | Benefit types and contributor roles are **tenant-wide**, not per-KPI |
| D2 | KPI selects which roles are applicable from the tenant pool (`KpiApplicableRole`) |
| D3 | Pre-seed common types and roles on tenant creation |
| D4 | Field templates gain optional `marker` property — backward compatible |
| D5 | Archiving blocked if entity is in use (contributor role in achievements, benefit type in policies) |

### Field Template Extension (in `shared.ts`)

Add optional `marker` to `AchievementFieldConfig`:

```typescript
// Add to achievementFieldSchema
marker: z.enum([
  "VALUE_FIELD",      // primary numeric (grant amount, revenue) — used by calc engine
  "CATEGORY_FIELD",   // determines tier (quartile, event level) — used by tier detection
  "UNIT_FIELD",       // per-unit calc input (participants, days)
  "SCORE_FIELD",      // contributes to score (feedback rating)
  "UNIQUE_CHECK",     // duplicate detection (DOI, patent #)
]).optional(),
```

Update pre-seeded templates with markers:
- PUBLICATION: `doi` → UNIQUE_CHECK, `indexing` → CATEGORY_FIELD
- GRANT: `sanctionedAmount` → VALUE_FIELD, `sanctionNumber` → UNIQUE_CHECK
- PATENT: `applicationNumber` → UNIQUE_CHECK, `status` → CATEGORY_FIELD
- CONFERENCE: `presentationType` → CATEGORY_FIELD
- TRAINING: `hours` → UNIT_FIELD

## Validation Rules
- BenefitType.code: unique per tenant, uppercase alphanumeric + underscore
- ContributorRole.code: same constraint
- defaultCreditPercent: 0–100 range
- Only TENANT_ADMIN or TENANT_OWNER can CRUD
- Archiving sets isActive=false, does not delete
- KpiApplicableRole: at least one role must be marked isDefault per KPI (the reporter's role)
