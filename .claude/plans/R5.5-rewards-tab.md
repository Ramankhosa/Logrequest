# R5.5 — "Rewards" Tab (Pipeline, Reconciliation, Export)

**Assigned to**: Codex (backend) + Opus (UI)
**Depends on**: R5.0 (scope resolver), R5.1 (shared components — DataTable, FilterBar, ConfirmDialog, ExportButton)
**Blocks**: Nothing

---

## Why This Exists

The reward engine (R4) generates `ContributorReward` records with states DRAFT→PENDING→RELEASED→REVOKED, but there's no UI for finance/approval authority users to manage these rewards. This tab provides the pipeline view (see all rewards, filter, bulk-transition), reconciliation view (grouped summaries for finance), and CSV export.

## Task 1: Backend — Reconciliation + Export Functions

### 1a. Add to `src/lib/kra-kpi/reward-ops-service.ts`

**`getRewardReconciliation(tenantId, periodId, groupBy, scopeUnitIds?)`**

```typescript
type ReconciliationRow = {
  groupKey: string;          // benefitTypeId, unitId, or periodId
  groupLabel: string;        // "Cash Award", "CS Department", "2025-26"
  draftCount: number;
  draftAmount: number;
  pendingCount: number;
  pendingAmount: number;
  releasedCount: number;
  releasedAmount: number;
  revokedCount: number;
  revokedAmount: number;
  totalCount: number;
  totalAmount: number;       // draft + pending + released (not revoked)
};

type ReconciliationResult = {
  rows: ReconciliationRow[];
  grandTotal: {
    draftAmount: number;
    pendingAmount: number;
    releasedAmount: number;
    revokedAmount: number;
    totalAmount: number;
    totalCount: number;
  };
};
```

**Logic**:
- Query `ContributorReward` grouped by the `groupBy` parameter:
  - `benefitType` → group by `benefitTypeId`, label from `benefitType.name`
  - `unit` → group by `rewardOwnerUnitId`, label from `rewardOwnerUnitName`
  - `kra` → group by KRA (via `kpiDefinition.kraDefinitionId`), label from KRA title
- Filter by `periodId` and `scopeUnitIds` (on `rewardOwnerUnitId`)
- Use Prisma `groupBy` with `_sum` and `_count` aggregations, grouped by state
- Compute grand totals from row sums

**`exportRewardsCSV(tenantId, periodId, filters?, scopeUnitIds?): Promise<string>`**

Returns a CSV string with headers:
```
Reward ID,Contributor,KPI,KRA,Benefit Type,Tier,Component,State,Base Amount,Final Amount,Unit,Release Reference,Released Date,Created Date
```

- Fetch all matching rewards using existing `listContributorRewards()`
- Map to CSV rows
- Return as string (route handler sets `Content-Type: text/csv` and `Content-Disposition: attachment`)

### 1b. Modify `listContributorRewards` in `reward-ops-service.ts`

Add optional `scopeUnitIds?: string[] | 'ALL'` parameter:
- If provided and not `'ALL'`, add `{ rewardOwnerUnitId: { in: scopeUnitIds } }` to the where clause
- Backward compatible: existing callers don't pass it

## Task 2: Backend — API Routes

### 2a. Create: `src/app/api/tenant/kra-kpi/rewards/reconciliation/route.ts`

GET:
- Query: `periodId, groupBy` (required: `benefitType` | `unit` | `kra`)

- Call `resolveUserDashboardScope()` for scope
- Call `getRewardReconciliation(tenantId, periodId, groupBy, scope.visibleUnitIds)`

- Call `exportRewardsCSV()`
