# R3.4 — Competitive Analysis, Cross-Check Intelligence & Reporting
# ═══════════════════════════════════════════════════════════════════════════════

## Goal

Three capabilities in one module:

1. **Competitive Analysis** — benchmark against peers using public data (NIRF, NAAC, NBA)
2. **Cross-Accreditation Intelligence** — overlap detection, consistency checks, drift alerts across concurrent filings
3. **Post-Filing Support** — DVV query tracking, peer team recommendation tracking, improvement planning

This is the **differentiator** that makes the product sticky.

Depends on: R3.1 + R3.2

---

## Design Decisions

1. **Competitor data is global** — NIRF/NAAC results are public. Stored at platform level, shared across tenants.
2. **Data entry**: Super admin bulk-imports public data (CSV/JSON). Future: automated scraping.
7. **Cross-accreditation intelligence** — automatic overlap detection across concurrent workspaces, consistency checks, drift alerts
8. **DVV query tracking** — track verification queries from accreditation body, assign responses, link to criteria
9. **Peer recommendation tracking** — post-visit recommendations with action plans and status tracking
3. **Peer groups** — institution defines its peer group (e.g., "Private engineering colleges in Maharashtra", "NIRF rank 50-100")
4. **Anonymized tenant data opt-in** — tenants can opt-in to share anonymized scores for richer benchmarks (future)
5. **Reports** — criterion-wise comparison, trend over years, strengths/weaknesses relative to peers
6. **SSR export deferred** — full Self-Study Report generation is R5 (AI layer) territory

## Schema (3 new models)

### Models

#### CompetitorInstitution
```prisma
model CompetitorInstitution {
  id              String              @id @default(cuid())
  name            String              // "IIT Bombay"
  code            String?             // "IITB" — short code
  city            String?
  state           String?
  country         String              @default("IN")
  institutionType String?             // "University", "Autonomous College", "Affiliated College"
  isActive        Boolean             @default(true)
  createdAt       DateTime            @default(now())
  updatedAt       DateTime            @updatedAt
  scores          CompetitorScore[]

  @@unique([name, country])
  @@index([state, institutionType])
}
```

#### CompetitorScore
```prisma
model CompetitorScore {
  id              String              @id @default(cuid())
  institutionId   String
  versionId       String              // which body+version (e.g., NIRF 2025)
  year            Int                 // ranking/assessment year
  overallScore    Float?
  overallRank     Int?
  grade           String?             // "A++", "A+", etc. (NAAC)
  outcome         String?             // "ACCREDITED", "RANKED"
  criterionScores Json?               // {criterionCode: {score, maxScore, rank?}}
  sourceUrl       String?             // public data source
  dataSource      String              @default("PUBLIC")  // "PUBLIC", "SCRAPED", "MANUAL"
  importedAt      DateTime            @default(now())
  institution     CompetitorInstitution @relation(fields: [institutionId], references: [id], onDelete: Cascade)
  version         AccreditationBodyVersion @relation(fields: [versionId], references: [id])

  @@unique([institutionId, versionId, year])
  @@index([versionId, year])
  @@index([institutionId])
}
```

#### DvvQuery
```prisma
model DvvQuery {
  id              String              @id @default(cuid())

  responseText    String?
  responseFileUrl String?

  createdByUserId String
  createdAt       DateTime            @default(now())
  updatedAt       DateTime            @updatedAt
```

#### PeerRecommendation
```prisma
model PeerRecommendation {
  id              String              @id @default(cuid())

  priority        String              @default("MEDIUM") // "HIGH", "MEDIUM", "LOW"

  actionPlan      String?             // "Sign 5 new MoUs by June 2025"

  // Meta
  createdByUserId String
  createdAt       DateTime            @default(now())

  @@index([workspaceId, status])
```


### `cross-accreditation-service.ts` (NEW)

```typescript
// ── Overlap Detection ──
getOverlapMap(tenantId, workspaceIds[]): Promise<OverlapReport>
// Groups all criterion data links by source (DataSource or KPI)
// Classifies overlaps: EXACT_MATCH (same source + same filters),
//   SUBSET (same source, tighter filters), DIFFERENT (same source, different filters)
// Returns: [{dataPoint, criteria: [{workspace, criterion, value, filters}], overlapType}]

// ── Consistency Check ──
checkConsistency(tenantId, workspaceIds[]): Promise<ConsistencyReport>
// For EXACT_MATCH overlaps: values MUST match → flag mismatches
// For SUBSET overlaps: verify subset math holds (part ≤ whole)
// Returns: {consistent[], explainableDiffs[], unexplainedMismatches[]}

// ── Reconciliation Report ──
getReconciliationReport(tenantId, workspaceIds[]): Promise<ReconciliationReport>
// Full cross-workspace comparison grouped by data point
// Shows: values per workspace, filter differences, drift status, recommendations
// Exportable for audit/committee review
```
